# דף עזר מהיר – Seedance

## נוסחת פרומפט
`Subject → Action → Setting → Camera → Look → Audio → Constraints`

## צ'קליסט לפני "Generate"
- [ ] נושא קונקרטי עם פרט מזהה אחד
- [ ] פעולה אחת ברורה + איך (מהירות/אופי)
- [ ] מצלמה: גודל שוט + תנועה אחת
- [ ] אור/סגנון בהגדרה מדויקת (לא רק "cinematic")
- [ ] סאונד מוגדר; דיאלוג במרכאות
- [ ] לכל רפרנס הוגדר תפקיד
- [ ] ניסוח חיובי, בלי סתירות
- [ ] יחס מסך ואורך מתאימים לפלטפורמה

## מילות מצלמה
static · dolly-in · pull-back · pan · tilt · tracking · orbit · crane · handheld · whip pan · rack focus

## מילות איכות
sharp focus · stable framing · natural motion · consistent character · shallow depth of field

## חוק האצבע לאיטרציה
משתנה אחד בכל ניסוי · שמרו מה עבד · 3 כשלונות = שנו גישה.
