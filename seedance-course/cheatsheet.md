# דף עזר מהיר

## המתכון
**נושא → פעולה → מקום → מצלמה → אור וסגנון → סאונד**

## צ'קליסט לפני "צור"
- [ ] הנושא מפורט (גיל, לבוש, צבע)
- [ ] פעולה אחת עם "איך"
- [ ] גודל שוט ותנועת מצלמה אחת
- [ ] אור מתואר בפועל (לא רק "קולנועי")
- [ ] סאונד מוגדר; דיבור במרכאות ובמשפט קצר
- [ ] לכל רפרנס הוגדר תפקיד
- [ ] ניסוח חיובי, בלי סתירות
- [ ] יחס מסך ואורך מתאימים למקום הפרסום

## מילות מצלמה
static · dolly-in · pull-back · pan · tilt · tracking · orbit · crane · handheld · whip pan · rack focus
