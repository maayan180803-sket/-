# פתרון תקלות

| בעיה | סיבה סבירה | פתרון |
|---|---|---|
| הדמות משתנה בין שוטים | אין character bible / רפרנס חלש | רפרנסים בכל שוט + תיאור קבוע |
| תנועה "מרחפת"/לא פיזיקלית | תיאור תנועה מעורפל או מהיר מדי | פעלים קונקרטיים, "slow/smooth", קצרו את השוט |
| ידיים/אצבעות משובשות | תנועת ידיים מורכבת | הרחיקו מהמצלמה, פשטו פעולה, שוט אחר |
| טקסט על המסך מעוות | טקסט ארוך/קטן | מילה קצרה וגדולה, או הוסיפו בעריכה |
| סנכרון שפתיים גרוע | משפט ארוך / כמה דוברים | משפט קצר, דובר אחד, קלוז-אפ |
| המודל התעלם מרפרנס | לא הוגדר תפקיד / יותר מדי רפרנסים | הגדירו תפקיד, צמצמו ל-1–3 |
| כל השוטים נראים שונים | סגנון לא נעול | משפט Look קבוע בכל פרומפט + רפרנס סגנון |
| התוצאה לא כמו בראש | פרומפט עמום | חזרו לנוסחה, הוסיפו פרטים קונקרטיים |
| בקשה נחסמה | מדיניות תוכן (פנים אמיתיות וכו') | השתמשו בדמות מקורית/נכסים שיש לכם זכות עליהם |
| עלות גבוהה | יותר מדי ניסיונות ברזולוציה גבוהה | טיוטות נמוכות, וריאציות מוגבלות |
