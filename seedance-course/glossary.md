# מילון מונחים

| מונח | הסבר פשוט |
|---|---|
| **AI (בינה מלאכותית)** | תוכנה שלמדה מהרבה דוגמאות וכעת יכולה ליצור תוכן חדש |
| **מודל** | ה"מוח" של התוכנה (כאן: Seedance) |
| **פרומפט** | הטקסט שכותבים כדי להגיד למודל מה ליצור |
| **שוט** | קטע צילום רצוף אחד בלי חיתוך |
| **סצנה** | כמה שוטים באותו מקום וזמן |
| **יצירה / Generation** | הפעולה של "צור" ויצירת הסרטון |
| **איטרציה** | חזרה על יצירה עם תיקונים |
| **קרדיטים** | "מטבעות" לתשלום על יצירות |
| **רפרנס** | קובץ שמעלים כדוגמה (תמונה/וידאו/שמע) |
| **סטורי-בורד** | תכנון השוטים לפני היצירה |
| **יחס מסך** | הצורה של המסגרת (16:9, 9:16 וכו') |
| **רזולוציה** | רמת חדות |
| **Seed** | מספר שקובע את נקודת ההתחלה האקראית של יצירה |
| **Close-up** | תקריב (פנים או פרט) |
| **Wide shot** | שוט רחב |
| **Dolly-in** | המצלמה מתקרבת לנושא |
| **Pan** | המצלמה מסתובבת לצדדים |
| **Tracking** | המצלמה נעה לצד הדמות |
| **Handheld** | מצלמה ביד, מראה "אמיתי" עם רעד |
| **עומק שדה רדוד** | הנושא חד והרקע מטושטש |
| **אמביינס** | רעשי רקע טבעיים של מקום |
| **סנכרון שפתיים** | תנועת השפתיים תואמת לדיבור |
| **QA** | בדיקת איכות לפני פרסום |
| **Character bible** | תיאור קבוע של דמות שמעתיקים לכל פרומפט |
