# קורס Seedance – מאפס למקצוען

קורס מעשי ליצירת וידאו ב-AI עם **Seedance** (מודל הווידאו של ByteDance), בנוי כך שבסופו תוכל/י להפיק קליפים מקצועיים, עקביים וחזרתיים – לא רק "ללחוץ ולקוות".

> **הערת עדכניות:** המודל מתעדכן מהר (2.0 → 2.5 בתוך חודשים). מגבלות (אורך, מספר רפרנסים, רזולוציה) משתנות לפי גרסה ופלטפורמה (fal, Artlist, Hedra, Dreamina ועוד). לפני כל פרויקט – בדקו את המגבלות בפלטפורמה שבה אתם עובדים. המספרים בקורס הם בסדר גודל, לא חוזה.

## למי זה מיועד
יוצרי תוכן, משווקים, מעצבים, עורכי וידאו וכל מי שרוצה להפוך רעיון לסרטון בלי צוות הפקה.

## שיטת הלמידה
1. **קרא** את המודול (20–30 דק').
2. **הרץ** את התרגילים – כל תרגיל מוגדר עם קריטריון הצלחה.
3. **תעד** ביומן ניסויים: פרומפט → תוצאה → מה לשנות. מקצוענות כאן = איטרציה מתועדת.
4. **שנה משתנה אחד** בכל ניסוי, אחרת לא תלמד/י מה השפיע.

## יומן ניסויים (תבנית)
```
תאריך | גרסת מודל | פרומפט | רפרנסים | הגדרות (אורך/יחס) | תוצאה 1-5 | מה לשפר
```

## הערות אתיקה ובטיחות (חלק מהמקצוענות)
- אל תשתמשו בפנים/קולות של אנשים אמיתיים בלי הסכמה; פלטפורמות רבות מגבילות זאת ממילא.
- שימו לב לזכויות יוצרים ברפרנסים (מוזיקה, דמויות, מותגים).
- סמנו תוכן שנוצר ב-AI כשהדבר נדרש (פלטפורמות חברתיות, פרסום, חוק מקומי).
