# מודול 8 – פרויקט סיום

## המשימה
להפיק סרטון של **30–60 שניות** מהרעיון ועד הקובץ הסופי.

## בחרו מסלול
1. **פרסומת מוצר** (מוצר דמיוני או מותג שלכם)
2. **טריילר** לסיפור קצר
3. **קליפ מוזיקלי** על טראק (שיש לכם זכויות עליו)
4. **סרטון הסברה/חינוך** עם דמות מנחה עקבית

## שלבים
1. בריף עמוד אחד: קהל, מסר, פלטפורמה, יחס מסך.
2. סטורי-בורד 8–15 שוטים (תבנית מודול 6).
3. Character sheet + רפרנסי סביבה (מודול 4).
4. טיוטות לכל שוט, בחירה, הפקה סופית.
5. עריכה, סאונד, כתוביות (מודול 7).
6. יצוא + סימון AI.
7. רפלקציה: מה למדתי, מה הייתי משנה, מה עלה כמה.

## מחוון הערכה (100 נק')
| קריטריון | נק' |
|---|---|
| סיפור/מסר ברור | 20 |
| עקביות דמות וסגנון | 20 |
| שפת מצלמה ותנועה | 15 |
| סאונד ודיאלוג | 15 |
| קצב ועריכה | 15 |
| QA וניקיון טכני | 10 |
| תיעוד ורפלקציה | 5 |

**90+** = רמה מקצועית · **75–89** = חזק, חסר ליטוש · **<75** = חזרו למודול החלש ביותר.

## אחרי הקורס
- בנו פורטפוליו של 3–5 קליפים.
- עקבו אחרי עדכוני מודל (Seedance מתעדכן מהר) ותעדכנו את ספריית הפרומפטים.
- הצטרפו לקהילות יוצרי AI-וידאו ושתפו ניסויים.
