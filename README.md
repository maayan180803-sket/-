## תקציב הדירה (apartment-dashboard.html)

דשבורד לניהול הוצאות והכנסות משותפות של הדירה. פתחו את הקובץ `apartment-dashboard.html` בדפדפן (אין צורך בהתקנה או שרת).

תכונות עיקריות:
- הוספת הוצאות והכנסות עם קטגוריה, תאריך, מי שילם/קיבל והערה
- חלוקת הוצאות לפי אחוז מותאם אישית (למשל 50/50) וחישוב אוטומטי של מי חייב למי
- גרפים: התפלגות הוצאות לפי קטגוריה, ומגמת הכנסות/הוצאות חודשית
- טבלת רשומות עם סינון לפי חודש ומחיקה
- תמיכה במצב כהה/בהיר
- ייצוא/ייבוא גיבוי (JSON) וייצוא ל-CSV לאקסל

הנתונים נשמרים מקומית בדפדפן (localStorage). כדי לשתף בין שני מכשירים — ייצאו גיבוי JSON במכשיר אחד וייבאו אותו בשני.
