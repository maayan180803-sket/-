# תיק עבודות — ניהול סושיאל לקליניקת קוסמטיקה (פרויקט קונספט)

**מעיין אליהו** · ניהול סושיאל · יצירת תוכן · עריכת סרטונים

זהו פרויקט קונספט שנועד להציג יכולות ניהול סושיאל, יצירת תוכן ועריכת וידאו,
דרך עסק פיקטיבי — **קליניקת נטע לביא**, קליניקה לקוסמטיקה וטיפוח עור בבאר שבע.
**אין** בפרויקט לקוחה אמיתית, תוצאות, המלצות או נתונים אמיתיים. כל הטקסטים
נכתבו באחריות, ללא הבטחות רפואיות או אבחון אישי.

כל התוכן בעברית, בכיוון כתיבה RTL, בפונטים תומכי-עברית (Heebo + Frank Ruhl
Libre, משורתים מקומית כדי שהכול יעבוד גם ללא אינטרנט).

## איך להחליף את שם הקליניקה / התמונות / פרטי הקשר

### שם הקליניקה, הצבעים והפונטים
הכול מרוכז במשתני CSS בקובץ **`assets/css/design-system.css`**, בתחילת
הקובץ תחת `:root`. שינוי שם הקליניקה שם *לא* מחליף אוטומטית טקסט בכל
הקבצים (כי הטקסט כתוב ישירות ב-HTML לצורך שליטה מלאה בעיצוב) — לכן הדרך
הכי מהירה להחלפה מלאה: חיפוש-והחלפה גלובלי של המחרוזות הבאות בכל
הפרויקט (בכל עורך קוד):

| מה להחליף | מופיע ב־ |
|---|---|
| `נטע לביא` (שם הקליניקה) | כל הקבצים |
| `@neta.lavi.clinic` (שם משתמש אינסטגרם) | grid-mockup, carousel, stories |
| `050-000-0000` (טלפון) | portfolio.html, reel-storyboard |
| `רחוב הרצל 00, באר שבע` (כתובת) | design-system.css (משתנה בלבד, לא מוצג כרגע בטקסט חופשי) |
| `your-email@example.com`, `linkedin.com/in/your-profile`, `@your.handle` | עמוד הסיום של תיק העבודות (עמוד 14) |

### תמונות
בכל מקום שאמור להיות תמונה אמיתית (חלל הקליניקה, בעלת העסק וכו') יש
תיבה מעוצבת עם מסגרת מקווקוות ותווית **"מקום לתמונה"** — קלאס
`photo-placeholder` (בתיק העבודות) או תיבות `texture` (במוקאפ האינסטגרם).
כדי להחליף: יש להחליף את ה-`div` בתגית `<img src="...">` עם התמונה
האמיתית, באותם מידות בערך.

## איך לייצא מחדש PNG / PDF אחרי עריכה

הפרויקט כולל סקריפט Node (עם Playwright) שממיר את כל קבצי ה-HTML
לתמונות ול-PDF באיכות גבוהה:

```bash
cd portfolio-cosmetic-clinic-demo
npm install            # פעם ראשונה בלבד
node scripts/render.js
```

הסקריפט כותב מחדש את כל התוכן בתיקיית `07-exports/` ואת קבצי ה-PDF
בתיקיות `01-portfolio-deck/` ו-`05-reel-storyboard/`.

כדי לעדכן את מסמך כל הטקסטים לאחר שינוי קופי:
```bash
node scripts/build-docx.js
```

## התאמה למובייל

כל התוצרים החזותיים (קרוסלה, סטוריז, מוקאפ האינסטגרם) מיוצאים ברזולוציה
ובממדים המדויקים של אינסטגרם (קרוסלה 1080×1350, סטורי 1080×1920), כך
שהם נראים חדים וברורים גם כשצופים בהם ישירות מהטלפון. תיק העבודות עצמו
מיועד לצפייה כ-PDF/מסמך (יחס עמוד נוח לגלילה גם במסך נייד).
