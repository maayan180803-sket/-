# תקציב משותף 💸

מערכת ניהול תקציב משותף לזוגות - הכנסות, הוצאות, תקציבים לפי קטגוריה, חלוקת הוצאות, מעבר דירה, מטרות חיסכון ועוד.
כל הנתונים נשמרים בענן (Supabase) ומסונכרנים בזמן אמת בין שני בני הזוג, מכל מכשיר.

## טכנולוגיה

React + TypeScript + Vite + Tailwind CSS v4 + Supabase (Auth / Postgres / Row Level Security / Realtime) + Recharts + PWA.

## שלב 1: יצירת פרויקט Supabase (חינמי)

1. היכנסו ל-[supabase.com](https://supabase.com) וצרו חשבון (או התחברו).
2. לחצו על **New Project**, תנו לו שם (למשל `shared-budget`) וסיסמת מסד נתונים, ובחרו אזור קרוב אליכם.
3. אחרי שהפרויקט מוכן, היכנסו ל-**SQL Editor** בתפריט הצד.
4. פתחו את הקובץ `supabase/schema.sql` מהפרויקט הזה, העתיקו את **כל** התוכן, הדביקו ב-SQL Editor ולחצו **Run**.
   זה ייצור את כל הטבלאות, ההרשאות (Row Level Security) והפונקציות הדרושות.
5. היכנסו ל-**Project Settings → API**. תצטרכו משם שני ערכים:
   - **Project URL**
   - **anon public key**

## שלב 2: הגדרת משתני סביבה

1. בתיקיית הפרויקט, העתיקו את הקובץ `.env.example` לקובץ בשם `.env`:
   ```bash
   cp .env.example .env
   ```
2. פתחו את `.env` והדביקו את הערכים מ-Supabase:
   ```
   VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```
   ⚠️ הקובץ `.env` לא מועלה ל-Git (הוא ב-`.gitignore`) - כך שהמפתחות שלכם נשארים פרטיים.

## שלב 3: התקנה והרצה

```bash
npm install
npm run dev
```

האתר יעלה בכתובת שתופיע בטרמינל (לרוב `http://localhost:5173`). פתחו אותה בדפדפן.

## שלב 4: הרשמה והתחלת עבודה

1. במסך הראשון לחצו על **"משתמש חדש - הרשמה"**, הזינו אימייל וסיסמה (של מעיין, למשל).
2. בהתחברות הראשונה תתבקשו **ליצור מרחב תקציב חדש** - תנו לו שם ותכתבו את השם שיוצג לבן/בת הזוג.
3. עברו למסך **הגדרות** ולחצו על **"קוד הזמנה חדש"** - שלחו את הקוד לבן/בת הזוג (וואטסאפ, מייל וכו').
4. בן/בת הזוג נרשמים במחשב/טלפון שלהם, ובמסך הראשון בוחרים **"הצטרפות עם קוד"**, מזינים את הקוד ואת השם שלהם.
5. מהרגע הזה שני המשתמשים רואים ומעדכנים את **אותו** תקציב משותף, בזמן אמת, מכל מכשיר.

### נתוני דוגמה (אופציונלי)

אחרי שיצרתם את המרחב המשותף (שלב 4.2), אפשר להריץ את `supabase/seed.sql` ב-SQL Editor של Supabase
כדי למלא את המערכת בכמה הכנסות, הוצאות, תקציבים ופריטי מעבר דירה לדוגמה - כדי להתרשם מהמערכת לפני שמתחילים להזין נתונים אמיתיים.
אפשר למחוק כל רשומה כזו בקלות ישירות מתוך המערכת (כפתור מחיקה בכל שורה).

## התקנה כאפליקציה בטלפון (PWA)

- **אנדרואיד (כרום):** פתחו את האתר → תפריט (⋮) → **"התקן אפליקציה"** / **"הוסף למסך הבית"**.
- **אייפון (ספארי):** פתחו את האתר → כפתור השיתוף (□↑) → **"הוסף למסך הבית"**.

לאחר ההתקנה האפליקציה תיפתח במסך מלא כמו אפליקציה רגילה, כולל עבודה אופליין חלקית בזכות ה-Service Worker.

## תצוגה מקדימה ללא Supabase (למפתחים)

אם רוצים לראות את המראה של המערכת לפני שמגדירים Supabase, אפשר להריץ `npm run dev` ולפתוח את `/preview.html` -
זו גרסה עם נתוני דמו קבועים בזיכרון (ללא שמירה אמיתית), רק לצורך הצגה חזותית של הממשק.

## מבנה הפרויקט

```
supabase/schema.sql      סכמת מסד הנתונים המלאה + הרשאות RLS + פונקציות RPC
supabase/seed.sql        נתוני דוגמה אופציונליים
src/lib/                 חיבור ל-Supabase, קבועים (קטגוריות וכו'), לוגיקת החישובים
src/types/                טיפוסי TypeScript התואמים לסכמה
src/contexts/            ניהול משתמש מחובר ומרחב התקציב המשותף
src/hooks/                גישה לנתונים מ-Supabase כולל סנכרון בזמן אמת (Realtime)
src/components/           רכיבי UI, טפסים ותפריטי ניווט
src/pages/                כל מסכי המערכת
```

## פקודות שימושיות

```bash
npm run build     # בנייה לייצור (כולל בדיקת טיפוסים)
npm run preview   # הרצת גרסת הייצור מקומית
```

## הערות אבטחה

- כל טבלה מוגנת ב-Row Level Security - משתמש יכול לראות ולערוך רק נתונים ששייכים למרחב התקציב שלו.
- מפתחות ה-Supabase ב-`.env` הם מפתחות ציבוריים (`anon key`) המיועדים לשימוש בצד לקוח, וההגנה האמיתית היא ה-RLS בצד השרת.
- לעולם אל תעלו את קובץ ה-`.env` שלכם (עם מפתחות אמיתיים) למקום ציבורי.
